# Plataforma de Vagas PHP

Projeto demonstrativo de uma plataforma de vagas desenvolvida com **PHP, MySQL, JavaScript, HTML e CSS**, com integração com **API REST**.

> Este repositório é uma versão limpa para portfólio. Dados reais, credenciais, logos originais, arquivos internos e informações sensíveis foram removidos ou substituídos por conteúdo demonstrativo.

## Tecnologias utilizadas

- PHP
- MySQL
- JavaScript
- HTML5
- CSS3
- API REST
- MVC em PHP
- Layout responsivo

## Funcionalidades principais

- Página inicial da plataforma
- Cadastro de candidato
- Login de candidato e recrutador
- Perfil do candidato
- Pesquisa e listagem de vagas
- Tela de detalhes da vaga
- Candidatura em vaga
- Área da empresa/recrutador
- Dashboard de vagas
- Visualização de candidatos
- Integração com API REST externa/local

## Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/plataforma-vagas-php.git
```

2. Coloque o projeto em um ambiente com PHP, como XAMPP ou Laragon.

3. Copie o arquivo de exemplo de ambiente:

```bash
cp .env.example .env
```

4. Configure os dados do banco de dados no `.env`.

5. Configure a URL da API REST no `.env`:

```env
API_BASE=http://localhost:8080
```

6. Acesse pelo navegador, por exemplo:

```text
http://localhost/plataforma-vagas-php/public
```

## Observações importantes

- O arquivo `.env` real não deve ser enviado para o GitHub.
- Este projeto depende de banco de dados MySQL e de uma API REST para algumas funcionalidades.
- Imagens, nomes e marcas originais foram substituídos por conteúdo genérico para manter o projeto seguro para portfólio.
